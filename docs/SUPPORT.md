# Getting Help

🇫🇷 [Version française](./SUPPORT.fr.md)

Meetup Killer (ParseAndCutV2) is a personal project, maintained by a single person in their spare time: there is no commercial support and no response-time guarantee.

## Before asking for help

1. Check [Troubleshooting.md](./Troubleshooting.md) — incidents already encountered are documented there, with the diagnostic steps that were followed.
2. For a failed transcription, note the message shown by the app: errors are explicit (unsupported format, file too large, silent recording, Groq unavailable...) and [development.md](./development.md#error-codes) explains each code.
3. Search the [existing issues](https://github.com/Alithiel31/ParseAndCutV2/issues), open and closed.

## Reporting a bug or requesting a feature

Open an [issue](https://github.com/Alithiel31/ParseAndCutV2/issues/new/choose) — the templates ask for the useful context (audio format and length, mode, browser or Android app, error message, job id if you have it). **Never paste a real `GROQ_API_KEY`**, and do not attach a recording you would not want to make public.

## Contributing

Development environment, reproducing the CI locally, commit conventions: see [CONTRIBUTING.md](./CONTRIBUTING.md).

## Reporting a security vulnerability

**Do not** use this channel for a security flaw — see [SECURITY.md](./SECURITY.md), which describes private reporting by email.
